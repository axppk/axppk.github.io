前言

时隔一年，重新开始写博客，一方面是最近工作轻松了些，有时间摸鱼了，一方面是长期一个人住，表达欲无处喧放。

AI的发展真的是日新月异，很多人在互联网上自嘲，“只要我学的够慢，就不用学”。

截至文章写下的日期，本人已连续四个月高强度使用Cdoex（GPT）开发，涉及Web网站开发，3D资源制作和优化，3D动画制作和优化，AI生图，AI动作，Unity游戏开发，引擎渲染技术逆向等。

强烈建议没有接触过Claude，Codex，DeepseekHarness的去了解下这些Agent的发展，已经日新月异了。截至2026/11/12日，当前实际体验下的AI排行（由于小版本更新迅速，以商家代称）如下：

  • Claude

  • GPT

  • Gemini

  • DeepSeek

  • Kimi

  • GLM

  • Grok

  • Qwen

Web网站开发影响

现在前后端均可以让Agent代行，以往的前后端职责分离，还得后期联调，服务器部署也需要相关知识。

但是大人时代变了，GPT可以直接前后端完整可以根据要求直接修改，默认回传检测的时候会同步修改前端调用和后端定义，以及数据库构成，方便快捷。极大提高了生产力，一个人一天即可开发完整的一个商业管理平台，包含用户端和管理端和服务器部署。

甚至部署可以写一个小工具，一键构建部署更新，附带更新说明。（看不懂Liunx？没关系，不需要看了）

3D资源制作

很遗憾，AI的3D资源实际上没有那么神乎其神，仍然还是起步状态。

  • Tripo当时测试的是国内版，效果一般。
  • Hi3D也是国内版，比Tripo还差。
  • 混元3D同样国内版，比Hi3D好，比Tripo效果差些。
  • Hyper3D当时测试时他对二次元模型有特化，但是有点贵没买。

主要问题就是无法细看，二次处理困难，包括不限于UV，贴图，面处理的问题。

3D动画制作

3D动画方面AI凭借视觉模块已经能理解大部分动作，并且能实现了，就算不是特化动作的GPT也能清楚理解你所表达的肢体动作。

  • Kimodo作为AI生成动作的本地模型，已经非常优秀，不过穿模情况仍然严重。
  • ARDY是云端的API式AI动作生成，可以和Kimodo配合使用，效果拔群。
